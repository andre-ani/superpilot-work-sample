# Work sample requirements

Paraphrased from the supplied Instagram Ads brief and the project owner's instructions. The original document is not included in this public repository.

Build an app that uses AI to create Instagram image ads that show the brand's actual products and reflect its visual identity. Prioritize a few hard problems: useful brand/product context, reliable product depiction, and judging the output. Short text is optional; the Instagram CTA button is outside the creative.

Required final deliverables:

1. A public GitHub repository with reproducible run instructions.
2. Generated ad images for at least three brands, in a folder or gallery.
3. A short `WRITEUP.md` covering the approach, results, failures/surprises, next steps, and unresolved problems.

Reference output sizes: 1080×1080 square, 1080×1350 portrait feed, or 1080×1920 stories. Export PNG or JPEG. Brand/model selection and the generation workflow remain open decisions.

Budget: up to six hours of active project work and $250 in project-only OpenRouter inference credit. Official start is October 26, 2026 at 18:20 America/Vancouver; submission is due October 27 at 12:00 in that timezone. Video, Meta integration, authentication, and deployment are outside the required scope.

The brief requests eventual email delivery. No email has been authorized or sent by this initialization task.
