# Generated ad examples

Six real production image-generation runs across **OLIPOP, Our Place, and Big Star Lights**. Each uses a different product/concept and produces four copy variations on one saved base: **24 composed PNGs** total. Square exports are **1080×1080**; Story exports are **1080×1920**.

Files below were downloaded through the app’s **Export all** action after all four variants were ready. Some headlines were shortened and optional supporting copy omitted to fit the verified text region at the minimum font size; original artwork and provider records were preserved. Product fidelity remains a human review judgment. Image-provider cost for these six runs was **$0.583044**, excluding planning and placement.
